# KINEX.js

**Build. Animate. Interact.**

KINEX.js is a lightweight, framework-independent JavaScript library designed to bring reusable components, animations and interactive experiences to modern websites.

Built with JavaScript, KINEX.js provides developers with ready-to-use components that can be integrated directly into existing web projects without requiring a specific frontend framework.

The library focuses on simplicity, customization and straightforward implementation through individual CDN-hosted files.

---

## Features

- **Framework Independent** — Use with standard HTML, CSS and JavaScript projects.
- **Reusable Components** — Ready-to-use interface components for modern websites.
- **Animations & Effects** — Add motion and interactive behaviour to web interfaces.
- **Customizable** — Adapt components to your project's design and requirements.
- **CDN Integration** — Access and implement individual components without installing a package.
- **Modular Structure** — Use only the components your project requires.

## Getting Started

### Using CDN

KINEX.js components can be integrated directly into an HTML document using their individual CDN links.

```html
<!-- Include the required KINEX.js component -->
<script src="YOUR_CDN_COMPONENT_URL"></script>
```

Add the component's required HTML and CSS to your project as specified in its documentation.

### Component Integration

Each component has its own implementation instructions, including:

- Component requirements
- HTML structure
- CSS styles
- JavaScript source
- CDN integration
- Customization details

Refer to the official KINEX.js showcase for component demonstrations and implementation examples.
